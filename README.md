# bnk.propimporter

Модуль для 1С-Битрикс, который копирует выбранные свойства из одного инфоблока в другой прямо из административной панели — вместе со списками значений (тип «Список») и всеми настройками свойства.

![Описание изображения](https://denisbunakov.ru/upload/resize_cache/webp/iblock/7eb/f0gt0jq36xaoss848reyjje3lmsk7fv0.webp)


## Возможности

- Выбор исходного и целевого инфоблока из выпадающих списков.
- Таблица свойств исходного инфоблока с фильтром по названию/коду и кнопкой «Выбрать все».
- Копирование выбранных свойств в целевой инфоблок со всеми параметрами (тип, множественность, `USER_TYPE`, `USER_TYPE_SETTINGS`, `LINK_IBLOCK_ID`, подсказки и т.д.).
- Для свойств типа «Список» (`L`) переносятся и значения списка.
- Защита от дублей: свойство с уже существующим в целевом инфоблоке кодом пропускается.

  
![Описание изображения](https://denisbunakov.ru/upload/resize_cache/webp/iblock/fe6/oepfn5rh33jn10dah22qr16bgrrhkds5.webp)

  

## Требования

- 1С-Битрикс с модулем `iblock`.
- PHP 7.4+.
- Права администратора для доступа к странице модуля.

![Установка](https://denisbunakov.ru/upload/resize_cache/webp/iblock/2ab/2dq9i0sjl7tg4ptyc40ecda0roj93k3l.webp)


## Установка

1. Скопируйте папку в `/bitrix/modules/bnk.propimporter/`.
2. Откройте **Настройки → Модули (Marketplace) → Установленные решения** и установите модуль **BNK: Импорт свойств инфоблока**.
3. Пункт меню появится в разделе **Контент → BNK: Импорт свойств**.

## Использование

1. Откройте **Контент → BNK: Импорт свойств → Импорт свойств**.
2. Выберите инфоблок «Откуда забрать» и «Куда переносим», нажмите **Сохранить**.
3. Отметьте нужные свойства (можно воспользоваться фильтром и «Выбрать все») и нажмите **Скопировать выбранные свойства**.
